## Phase Goal

**As a** user who needs better timing precision, **I want to** connect an external GPS receiver, **so that** LapSight can exceed phone GPS limitations.

(Narrowed scope for this gap-closure plan: ROADMAP Success Criterion 4 requires the UI to expose external GNSS "connection/status." A full `ExternalGnssConnectionState` state machine already exists — `androidApp/src/main/kotlin/com/huanfuli/lapsight/ExternalGnssLocationProvider.kt:46-51` — but per `06-VERIFICATION.md` it was never threaded into Compose UI. This plan closes exactly that gap by copying the existing `GlassesSettingsCard`/`glassesConnectionState` wiring pattern in the same files, per `06-PATTERNS.md`.)

**Explicit scope decision (per this gap-closure's instructions):** Of the review findings in `06-REVIEW.md`, only IN-01 is folded into this plan, because it is a two-line reorder inside the exact `sourceNote` block this plan already touches. CR-01 (RaceBox sync-byte-split data loss) and WR-03/WR-04 (NMEA parser buffer/accuracy bugs) are addressed in the sibling plan `06-06-PLAN.md` (independent files, same wave).
